🌸 kawaii-notes ✨

A cute, cozy, and aesthetically pleasing space to organize your thoughts, jot down daily reminders, or sketch out your biggest ideas. 🧸🍒

🌸 Features
- Aesthetic & Cozy UI: Designed to be easy on the eyes and comforting to use.
- Effortless Note-Taking: Quick, seamless markdown rendering or rich text editing.
- Custom Themes: Switch between pastel pink, soft lavender, mint green, and warm milk tea color palettes.
- Easy Organization: Categorize your notes with adorable tags and folders.
- Secure & Local: Keeps your thoughts safe and private.

🚀 Quick Start
1. Clone the repository:
   git clone https://github.com/demoonlightt/kawaii-notes.git

2. Install the dependencies:
   cd kawaii-notes && npm install

3. Run the development server:
   npm run dev

Open http://localhost:3000 to start using your cute note-taking app! 🎉
